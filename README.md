# Early Bruising Identification on Apple Skin Leveraging Hyperspectral Images and Neural Networks

This repository contains the code and documentation for the paper "Early Bruising Identification on Apple Skin Leveraging Hyperspectral Images and Neural Networks".

The work focuses on early apple skin bruising identification from hyperspectral images using neural network models and related analysis workflows developed as part of HIPPA, "Hyperspectral imaging for the detection of physiologically and parasitically induced damages on apple fruit at harvest and during postharvest".

## Project Structure

- `src/bruising_detection/` - data loading, model training, PCA-SVM experiments, visualization, and configuration code.
- `eda/` - exploratory analysis notebooks.
- `docs/` - project notes, methods, and sharing documentation.
- `tests/` - test code.
- `.github/` - GitHub workflow and repository configuration.
